# Context Rules

**This file is not modified. It governs everything under `context/`.**

- Do not edit this file to register a new subfolder, path, or document.
- To index the layout of `context/`, create a `README.md` here — current state only.

## What context/ is

**A backlog of today. Not a changelog.**

- Holds what an agent needs to act right now.
- Does not accumulate how it got here. That is git.

**A pointer, not a copy.**

- The chain is `context/ → docs/ → project`.
- `context/` says where to look and how to behave.
- `docs/` holds the domain truth. The code is the ground truth.
- Never copy from `docs/` into `context/`. Link to it.

## Writing in context/

- One concern per file. If a file covers two, split it.
- Write in present tense. No dates, no history, no "previously".
- If it stops being true, rewrite it. Do not append a correction.
- If it stops being useful, delete it. Git keeps it.
